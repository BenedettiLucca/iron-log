## Pure helper contracts

### `src/utils/body-metrics.ts`

Add only these small shared helpers — no class/framework:

```ts
type MetricTrendDirection = 'up' | 'down' | 'stable' | 'unavailable';
type MetricTrend = { delta: number | null; direction: MetricTrendDirection };

getMetricTrend(
  current: number | null | undefined,
  previous: number | null | undefined,
  epsilon?: number,
): MetricTrend

getPercentageTrend(
  current: number | null | undefined,
  previous: number | null | undefined,
  epsilon?: number,
): MetricTrend

isDisplayableBodyMetricValue(value: unknown): value is number
```

Rules:
- missing/non-finite => `{ delta: null, direction: 'unavailable' }`;
- percentage previous `0` => unavailable, never Infinity or invented progress;
- `abs(delta) < epsilon` => stable and normalized `delta: 0`;
- percentage delta is standard percent change;
- displayable body metric accepts finite `0..999`, rejects null/negative/>999/NaN/Infinity;
- preserve existing exports.

## Analytics screen

### Data model and windows

- Define an explicit key-stats type whose `recentAvgRpe` and `recentAvgDur` are `number | null`.
- Add `recentSessionsCount` from actual sessions in the last 30 rolling days. Use this in the headline — do not label calendar-month count as 30d.
- `recentVolume` zero is valid.
- sRPE/duration with no recent samples are null and display `—`.
